<h1>ChatFlow</h1>
<P>What is chatFlow</P>
<P>ChatFlow is a WhatsApp clone—you can send messages just like on WhatsApp. </P>


<h2>What's so special about ChatFlow?</h2>
<P>What makes ChatFlow so special is that it has no backend—everything runs locally in the browser.</P>


<h3>A quick note</h3>
<PIt's not like WhatsApp—it's all simulated: no real contacts, no real numbers—it's all simulated.></P>
